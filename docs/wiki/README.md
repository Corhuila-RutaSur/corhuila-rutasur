# Contenido para la Wiki de GitHub

Esta carpeta contiene las páginas Markdown preparadas para la wiki de GitHub. Se mantienen versionadas junto con el código para que la documentación pueda revisarse mediante pull requests.

## Publicación

1. Habilita la Wiki desde la pestaña **Wiki** del repositorio en GitHub y crea la página inicial.
2. Clona el repositorio de la wiki que GitHub proporciona: `https://github.com/<organizacion-o-usuario>/<repositorio>.wiki.git`.
3. Copia el contenido de esta carpeta a la raíz de ese repositorio wiki.
4. Confirma y publica los cambios desde la rama predeterminada de la wiki.

`Home.md` será la portada y `_Sidebar.md` el menú lateral de la wiki.

No edites únicamente la wiki remota: primero actualiza estos archivos para conservar una fuente versionada en el repositorio principal.
