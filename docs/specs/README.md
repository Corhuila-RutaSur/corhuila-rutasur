# Especificaciones funcionales

Cada funcionalidad nueva debe tener una especificación antes de su implementación. Utiliza la plantilla de `plantilla-spec.md` y nombra los archivos con un prefijo numérico, por ejemplo: `001-gestion-rutas.md`.

Una especificación define qué debe hacer el sistema. No debe imponer detalles internos de código salvo que sean parte del contrato o una restricción explícita.
