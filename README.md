# RutaSur

Proyecto para el aplicativo RutaSur, compuesto por un frontend Angular y un backend Spring Boot.

## Estructura

- `apps/web`: frontend Angular.
- `apps/api`: backend Spring Boot.
- `docs/specs`: especificaciones funcionales y criterios de aceptación.
- `docs/architecture`: documentación de arquitectura y contratos.
- `docs/adr`: decisiones arquitectónicas.
- `docs/standards`: estándares compartidos.

Antes de implementar una funcionalidad, consulta las reglas de [AGENTS.md](AGENTS.md) y crea o actualiza la especificación correspondiente.
